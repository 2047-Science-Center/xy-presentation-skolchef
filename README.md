# X&Y – presentation för skolchefer

Kort, självgående presentation (svenska) som introducerar X&Y för skolchefer:
varför insatsen behövs, hur aktiviteten går till, och vad den ger. Byggd med
steg-för-steg-uppbyggnad. En variant av huvudpresentationen (xy-presentation).

Öppna `index.html` i en webbläsare, eller via GitHub Pages. Navigera med
piltangenter, mellanslag eller klick.
